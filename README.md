I'm currently working on **FlexPrice**, an open-source billing and pricing platform.

My work sits close to the intersection of **engineering, product, and design** — building interfaces for pricing, usage, subscriptions, credits, customers, and billing workflows.

I started out thinking software engineering was mostly about writing code.

These days, I spend just as much time thinking about **why something should exist, how it should behave, how users will understand it, and what happens after it ships.**
